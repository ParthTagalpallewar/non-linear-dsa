# Shortest Paths

Single-source algorithms measure the distance from one start to every vertex.
Multi-source algorithms measure each vertex's distance to its nearest
source, treating every source as initially reachable at zero cost. All-pairs
algorithms produce a distance for each ordered pair. Unreachable distances
are represented by infinity. Negative cycles make the distance to affected
vertices unbounded below.
