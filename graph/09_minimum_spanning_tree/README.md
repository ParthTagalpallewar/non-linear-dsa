# Minimum Spanning Trees

A minimum spanning tree connects every vertex of a connected undirected
weighted graph with minimum total edge weight. Disconnected inputs yield a
minimum spanning forest, with one tree per component. All implementations
here accept an edge list of (source, target, weight) records and return the
edges selected for that forest. Negative weights and parallel edges are
allowed. The vertex count includes isolated vertices.
