# Graph traversal

Breadth-first search uses a queue to explore in increasing edge distance.
Depth-first search follows one branch at a time and backtracks to explore the
rest. Both track visited vertices to terminate on cycles. On grids the
neighbor relation comes from movement rules instead of an explicit graph.
