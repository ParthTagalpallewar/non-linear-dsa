# Special Graph Paths

An Euler walk uses every edge exactly once and may revisit vertices. A Hamiltonian path visits every vertex once and may omit edges. Euler questions can be reduced to degree parity and connectivity. General Hamiltonian problems require exponential search in the worst case.
