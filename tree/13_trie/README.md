# Tries

A trie shares leading characters or bits between keys. Each root-to-node path encodes a prefix. A terminal marker distinguishes a complete word from a prefix. Fixed-width binary tries can prioritize high bits when maximizing XOR. See the [full node and trie definitions](../tries.py).
