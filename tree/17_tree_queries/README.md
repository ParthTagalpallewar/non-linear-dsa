# Tree Queries

Preprocessing is worthwhile when many queries share one tree. Binary lifting indexes powers-of-two ancestors. A preorder tour makes subtrees contiguous. A full Euler walk supports LCA by depth minima. Static path sums combine root prefixes with LCA. See [shared query implementations](../queries.py).
