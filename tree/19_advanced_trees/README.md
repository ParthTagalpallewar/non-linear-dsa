# Advanced Tree Algorithms

Heavy-light decomposition maps arbitrary paths to logarithmically many chain segments. Centroid decomposition recursively removes balanced separators. Small-to-large merging reuses subtree state. Canonical encodings compare shapes or represent labeled trees as short sequences.
