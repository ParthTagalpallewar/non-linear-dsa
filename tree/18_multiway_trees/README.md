# Multiway Trees

An N-ary tree gives a node an ordered sequence of children. Search
trees with several keys per node can keep their height low by increasing
fanout. A B-tree stores records in leaves and internal nodes. A B+ tree
stores records only in leaves, with internal copies that route searches
to the right child on equality. Its linked leaves support range scans.
Read the full [B-tree](../b_tree.py) and [B+ tree](../b_plus_tree.py) implementations.
