# Tree Construction

With distinct keys, inorder plus either preorder or postorder uniquely determines a binary tree. Preorder and postorder alone cannot distinguish a sole left child from a sole right child. Requiring every internal node to have two children removes that ambiguity. BST ordering supplies missing boundaries for preorder alone. Duplicates require an extra convention or node identifiers.
